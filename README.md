# 🛡️ Cybersecurity Incident Analysis

> Real-world security case studies, incident analysis & awareness training — CYB-200 at SNHU

## Overview
This repository contains three projects from my Cybersecurity Foundations course, each tackling a different dimension of real-world security work: security awareness training, incident analysis, and applying security principles in a government context.

---

## 📁 Projects

### Project 1 — Security Awareness Training Case Study
**Objective:** Develop a security awareness training program for an organization.

**Content covered:**
- Identifying human factors and social engineering threats
- Designing training content tailored to different user roles
- Addressing legal and ethical considerations in security training
- Measuring training effectiveness

**Skills demonstrated:** Security awareness program design, communication, human risk factors, training development

**Real-world relevance:** Security awareness is one of the most impactful (and underrated) controls in any organization. This project mirrors work done by real security analysts responsible for awareness programs.

---

### Project 2 — Incident Analysis Brief
**Objective:** Analyze a real-world cybersecurity incident and produce a professional incident brief.

**Content covered:**
- Identifying the threat actor type and attack methodology
- Analyzing the timeline and impact of the incident
- Assessing the organization's response
- Recommending improvements to detection and response

**Skills demonstrated:** Incident analysis, threat characterization, root cause analysis, security reporting

---

### Project 3 — Security Training as a Government Agency Employee
**Objective:** Apply cybersecurity principles and legal frameworks in the context of a government organization.

**Content covered:**
- Federal cybersecurity laws and compliance requirements
- Insider threat awareness
- Handling sensitive information securely
- Reporting obligations and escalation procedures

**Skills demonstrated:** Compliance awareness, policy understanding, government security frameworks, ethical decision-making

## 🔑 Key Takeaways
These projects taught me that cybersecurity isn't just technical — it's deeply human. Understanding how people are targeted, how incidents unfold, and how to communicate findings clearly are skills every security analyst needs. Writing these briefs gave me practice translating technical findings into clear, actionable narratives for stakeholders.
