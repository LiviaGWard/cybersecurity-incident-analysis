# Module Three Activity: Privacy Protection Case Study
**CYB-200 | Cybersecurity Foundations**

## Objective
Evaluate a set of security control recommendations against the 7 fundamental security design principles, identify which principle(s) each control applies to, and provide written justification aligned with CIA Triad objectives.

---

## Security Design Principles Reference

| Principle | Description |
|---|---|
| **Isolation** | Separate systems/components to limit blast radius of a breach |
| **Encapsulation** | Hide internal details; expose only what's necessary |
| **Complete Mediation** | Every access request must be verified — no exceptions |
| **Minimize Trust Surface** | Reduce the number of trusted entities and entry points |
| **Trust Relationships** | Define and control which entities are trusted and to what degree |
| **Security Objective Alignment** | Controls must map to CIA Triad goals |

---

## Control Evaluation

### Control 1 — Automated Perimeter Monitoring Tool
*Monitors for unauthorized transfer of sensitive data; blocks transfers and alerts security professionals.*

| Principle Applied | CIA Alignment | Justification |
|---|---|---|
| Complete Mediation | **Confidentiality** | All data transfers are checked and verified — no transfer escapes scrutiny. This ensures sensitive information cannot leave the network without authorization. |

---

### Control 2 — Monitor All Outbound Traffic
*Continuous monitoring of all traffic leaving the organization's network.*

| Principle Applied | CIA Alignment | Justification |
|---|---|---|
| Complete Mediation | **Confidentiality** | Consistent outbound traffic monitoring ensures no unauthorized data exfiltration occurs, directly protecting confidentiality of sensitive information. |

---

## Key Takeaway
Complete Mediation is particularly powerful for privacy protection because it closes the gap that partial monitoring leaves open — every access, every transfer, every request must pass through a check. There are no trusted shortcuts.
